## v0.4.0 — 可点击的引用 chip，引用链路与大纲正确性

本版的主线是「选中文字 → 添加到对话」不再把整段围栏块塞进输入框，而是落成一枚可点击的引用 chip；同时修复了上一轮全量审查里的大纲 / 分词 / 配置问题，并加固发布门禁。tag 还包含超长单行文件的纯文本回退修复。

### 引用 chip

- 选区落成一枚 `引用 文件 L起-止` 的紧凑 chip（与 better-sidebar 0.30 同形）；输入框保持紧凑，**发送时**才展开成与内置查看器逐字节相同的 `相对路径:起止行` 围栏块（>500 字只留路径行）。
- 引用数据直接放在 chip 自己的 ref 里（`cnq1:` + JSON：path / cwd / lines / label / clipboardText / text），**不写 localStorage**：刷新、换标签页、清空站点数据都不会把 chip 变死。
- 点击 chip 跳回源文件并闪烁被引行段（需要 better-sidebar 0.30 把 `line` / `lineEnd` 交给预览器；更旧版本仍能落 chip 并正确展开，只是点击不定位行）。
- 宿主没有 chip 通道（无 `inputTriggers`）时按降级链回退：本插件自带的纯文本 chip（`codeNavQuoteText`，仍是一枚紧凑 chip、发送时原样展开）→ 直接插入围栏块；旧版宿主再回退 `setDraft`，能力不丢失。

### 大纲 / 分词 / 配置修复

- **大纲**：方法体 `const/let/var`（含 Swift / Kotlin `let/val`）不再被当成外层类字段；TS/JS 泛型函数 / 方法 / 箭头、Swift `init`/`subscript`、Kotlin 次构造、单行多成员、嵌套函数、C++ 构造/析构声明、Ruby end 作用域容器、Go grouped 声明与类型别名、Python 类属性、Swift protocol 要求、同行 C++ 模板类均能正确列出。
- **分词**：properties 续行、Vue/Svelte `</script>` 的正则/字符串/注释扫描、YAML 块标量头线性、PHP 8 `#[...]` 属性；500 KB 内容上限真正截断时界面给出提示，不再静默。
- **配置大纲**：YAML 多文档重置、序列容器、单行/多行 flow mapping、TOML 引号段头、dotenv 多行引号值、XML close-tag 匹配线性化。

### 客户端

- 查找跟随当前匹配（包括只有一条匹配时按 Enter 也能滚动）；宿主没有暴露 quotes 时对 chip 的 detect 投影做保守补偿；chip 打开失败会走输入框提示；a11y：键盘入口、模态弹层焦点陷阱、live region 播报、大纲空态准确。

### English

**v0.4.0 — clickable quote chips, quote-pipeline and outline correctness**

The headline is that "add to conversation" no longer dumps a whole fenced block into the composer: the selection becomes a compact, clickable quote chip. This release also closes the outline / tokenizer / config issues from the previous full review and hardens the release gates. The tag additionally contains the plain-text fallback for very long lines.

**Quote chip**

- The selection lands as a compact `Quote <file> Lstart[-end]` chip (same shape as better-sidebar 0.30). The draft stays compact and the chip **expands on send** into the same `relative/path:start[-end]` fenced block the built-in viewer produces, byte for byte (over 500 characters keeps the path line only).
- The payload lives in the chip's own ref (`cnq1:` + JSON: path / cwd / lines / label / clipboardText / text) and is **never written to localStorage**: a refresh, another tab or cleared site data cannot kill it.
- Clicking the chip jumps back to the source file and flashes the quoted lines (needs better-sidebar 0.30 to hand `line` / `lineEnd` to the viewer; older versions still get the chip and correct send-time expansion, but the click only opens the file).
- Hosts without a chip channel (no `inputTriggers`) fall back along this chain: the plugin's own plain-text chip (`codeNavQuoteText`, still compact and expanded verbatim on send) → inserting the fenced block directly; older hosts then fall back to `setDraft`, so the capability is never lost.

**Outline / tokenizer / config fixes**

- **Outline**: method-body `const/let/var` (including Swift / Kotlin `let/val`) are no longer treated as fields of the outer class; TS/JS generic functions / methods / arrows, Swift `init`/`subscript`, Kotlin secondary constructors, several members on one line, nested functions, C++ constructor/destructor declarations, Ruby end-scoped containers, Go grouped declarations and type aliases, Python class attributes, Swift protocol requirements and same-line C++ template classes all list correctly.
- **Tokenizer**: properties continuations; Vue/Svelte `</script>` scanning through regexes, strings and comments; linear-time YAML block-scalar headers; PHP 8 `#[...]` attributes; and the 500 KB content cap now produces a visible notice instead of silently truncating.
- **Config outline**: YAML multi-document reset, sequence containers, single- and multi-line flow mappings, TOML quoted section names, dotenv multiline quoted values, and linear-time XML close-tag matching.

**Client**

- Find follows the current match (including Enter with a single match); the chip's detect projection is compensated conservatively when the host exposes no quotes; chip-open failures surface a composer notice; accessibility: keyboard entry, modal focus trap, live-region announcement and an accurate outline empty state.

**Build / release / docs**

- Reproducible LF bundle; `lib/index.js` syntax gate; `node --test` auto-discovery; `verify-pack` content/size checks; a pre-release tarball freshness gate (no "edited after npm pack"); PAT redaction in the PR script; CI order guards; READMEs synced with the 307-test suite.

**Very long lines**

- Lines over **8,000 characters** or **500 highlight segments** render as plain text (one text node); the content stays byte-identical, selection / search / jumping still work, and the current match remains highlighted (three spans) with a notice. A 928 KB one-line JSON no longer wedges Chromium layout. Tests 307 → **309**.

**Validation**

- `npm test` — **309/309** pass (including byte-for-byte committed-vs-fresh bundle equality)
- rebuilt `lib/client.js`: **307,650 bytes**, md5 `d8273bd48a95b7acf354b37b2f24d7b0`
- `node --check lib/client.js` — clean
- `npm pack` — 7 files; the release rehearsal (`--dry-run`) passes
- Desktop checks: chip landing / click-through, outline jumps and the long-line fallback all behave as expected
