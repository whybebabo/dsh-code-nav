## v0.1.2 — 修正安装文档：只支持 web profile

0.1.1 的 tarball 里还写着 `dsh plugin --profile desktop add ...`，这条命令不可能成功：desktop profile 由 Electron 应用独占管理，CLI 写入会被拒绝。npm 不能修改已发布版本，所以 README 的修正只能通过新版本送达用户。

### 修正

- 两份 README 与 `cordis.patch.yml` 注释去掉 desktop 安装方式，统一为 `--profile web`；桌面版说明改为「在应用内插件页安装」。
- 记录 scoped 安装时应用插件管理器会将该版本写入 `minimumReleaseAgeExclude`（pnpm 对刚发布版本的预期行为）。
- 版本号 0.1.2；客户端 bundle 不含版本字符串，重建后与 0.1.1 **逐字节相同**，选区 → 添加到对话的行为完全不变。

### 验证

- `node test/code-nav.test.mjs` — **28/28** 通过
- `node --check lib/client.js` — 通过
- `lib/client.js` 重建：**91,023 字节**，md5 `9db1715fcc4ead0a4789377463f9eff3`（与 0.1.1 相同）
- `npm pack` 的 tarball 内两份 README 不再包含 `--profile desktop`

### 安装

```bash
dsh plugin --profile web add @whybebabo/dsh-code-nav@0.1.2
# 或
dsh plugin --profile web add github:whybebabo/dsh-code-nav#v0.1.2
```

安装后重启 `dsh web` 并硬刷新浏览器。桌面版请在应用内插件页安装。

### English

**v0.1.2 — corrected install docs: web profile only**

The 0.1.1 tarball still documented `dsh plugin --profile desktop add ...`, which cannot work: the desktop profile is owned exclusively by the Electron app and rejects the CLI. npm cannot amend a published version, so the README fix can only reach users through a new release.

**Fix**

- Both READMEs and the `cordis.patch.yml` comment drop the desktop install path and use `--profile web`; the desktop note now says to install from the in-app plugin page.
- The docs record that the app's plugin manager adds a just-published scoped version to `minimumReleaseAgeExclude` (expected pnpm behaviour).
- Version 0.1.2. The client bundle embeds no version string, so the rebuilt `lib/client.js` is **byte-identical** to 0.1.1 and selection → add to conversation behaves exactly as before.

**Validation**

- `node test/code-nav.test.mjs` — **28/28** pass
- `node --check lib/client.js` — clean
- rebuilt `lib/client.js`: **91,023 bytes**, md5 `9db1715fcc4ead0a4789377463f9eff3` (same as 0.1.1)
- the packed tarball's READMEs contain no `--profile desktop`

```bash
dsh plugin --profile web add @whybebabo/dsh-code-nav@0.1.2
# or
dsh plugin --profile web add github:whybebabo/dsh-code-nav#v0.1.2
```

Restart `dsh web` and hard-refresh after installing. On the desktop app, install from the in-app plugin page.
