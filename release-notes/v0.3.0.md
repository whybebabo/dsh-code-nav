## v0.3.0 — Protocol Buffers 高亮与大纲

新增 `.proto` 支持：语言识别、语法高亮与符号大纲。proto2 / proto3 的常见结构都能进侧栏，嵌套与容器列也一致。

### 高亮

- `.proto` → `protobuf`，支持 `//` 与 `/* */` 注释、双引号字符串，以及 proto2 / proto3 的关键字与标量类型集合。

### 大纲

- `message` / `enum` / `oneof` / `service` / `extend` 打开容器，嵌套层级与「容器」列正常工作。
- `rpc` 成为方法；字段（含 `optional` / `repeated` / `required` 标签与 `map<...>`）与枚举值成为符号。
- proto2 的 `group` 显示为字段但打开自己的作用域，成员挂在组名下。
- 类型名与 `extend` 目标接受 `.foo.Bar` 这种全限定形式。
- 常量（包括枚举值与类常量）现在像方法 / 字段一样继承容器。

### 文档

- 两份 README 更新到 0.3.0（banner、升级示例、版本历史、fork 对比表、支持语言表），并修正「只支持 web」的说法：插件在 Electron 桌面端也能运行，只是 CLI 不能写 desktop profile，桌面版请从应用内插件页安装。

### English

**v0.3.0 — Protocol Buffers highlighting and outline**

Adds `.proto` support: language detection, syntax highlighting and a symbol outline. The usual proto2 / proto3 shapes reach the sidebar with correct nesting and container text.

**Highlighting**

- `.proto` → `protobuf`, with `//` and `/* */` comments, double-quoted strings, and the proto2 / proto3 keyword and scalar-type sets.

**Outline**

- `message` / `enum` / `oneof` / `service` / `extend` open containers, so nesting and the "container" column work.
- `rpc` becomes a method; fields (including `optional` / `repeated` / `required` labels and `map<...>`) and enum values become symbols.
- A proto2 `group` shows as a field but opens its own scope, so its members nest under the group name.
- Type names and `extend` targets accept the fully-qualified `.foo.Bar` form.
- Constants (including enum values and class constants) now inherit their container the way methods and fields already did.

**Docs**

- Both READMEs move to 0.3.0 (banner, upgrade example, changelog, fork table, supported languages) and drop the incorrect "web only" claim: the plugin also runs in the Electron desktop app — only the CLI cannot write the desktop profile, so install it from the in-app plugin page there.
