## v0.1.1 — 以 fork 身份发布，补上「选中文字 → 添加到对话」

本版是这个 fork 的第一次公开发布：包名改为 `@whybebabo/dsh-code-nav` 并发布到 npm，同时补上上游缺失的「选中文字 → 添加到对话」——上游以更高优先级接管代码预览后，better-sidebar 内置查看器里的这个入口会消失，这是 fork 存在的直接原因。

### 选中文字 → 添加到对话

- 在预览里划选任意代码，选区上方浮出「添加到对话」按钮；点击后按内置查看器的同一形状插入 `相对路径:起止行` 围栏代码块（超过 500 字只留路径行），路径相对会话 cwd。
- 行号取自渲染出的行容器、正文取自每行的代码列，`user-select:none` 的行号槽不会混入选区文本；终点正好落在下一行行首时，行区间自动收窄一行。
- 插入优先走会话输入框的 `captureInsertion` / `insertText`（一次撤销、保留已有引用 chip、输入框忙时不动草稿），旧宿主回退到 `setDraft`。
- 浮层沿用 better-sidebar 的关闭契约：外部点击、Esc、页面隐藏、窗口失焦、滚动、面板离开视口。

### 以 fork 身份发布

- 包名 `@whybebabo/dsh-code-nav`，`publishConfig.access = public`（scoped 包默认 restricted），`repository` / `homepage` / `bugs` 指向 fork，并导出 `cordis.patch.yml`。
- 构建期从 `package.json` 注入客户端 bundle 的注册 id；client-modules 用完整包名做 module table key，写死短名会报 `loaded without registering`。
- loader entry 的 `name` 用完整包名、`id` 保持短本地标签；README 增加 fork 来源、与上游的差异表、正确安装命令、不要与上游同时安装的警告和 MIT 归属。
- 附带两个维护脚本：`repo-topics.mjs` 合并式设置仓库 topics；`pr-better-sidebar.mjs` 生成上游目录 PR（plugins-viewers 条目 + zh/en/ja locales）。

### 安装

```bash
# npm
dsh plugin --profile web add @whybebabo/dsh-code-nav@0.1.1

# 或直接从仓库 tag 安装
dsh plugin --profile web add github:whybebabo/dsh-code-nav#v0.1.1
```

安装后重启 `dsh web` 并硬刷新浏览器。不要与上游 `dsh-code-nav` 同时安装（两者注册同一个预览器 id）。

### English

**v0.1.1 — first publish as a fork, plus selection → add to conversation**

This is the fork's first public release: it publishes under the scoped name `@whybebabo/dsh-code-nav` and restores the "selection → add to conversation" affordance that upstream loses when its higher-priority viewer takes over code previews.

**Selection → add to conversation**

- Selecting code in the preview floats the same button above the selection; clicking it inserts a fenced block headed by `relative/path:start[-end]`, matching the built-in viewer's payload shape (selections over 500 characters keep the path line only) and resolving the path against the session cwd.
- Line numbers come from the rendered line containers and text from the per-line code column, so the `user-select:none` gutter never leaks into the payload; a selection ending exactly at the next line start narrows the span by one line.
- Insertion prefers the composer's `captureInsertion` / `insertText` actions (one undo step, existing reference chips preserved, no draft mutation while the composer is busy), falling back to `setDraft` on older hosts.
- The popup follows better-sidebar's dismissal contract: outside mousedown, Escape, hidden document, window blur, scroll, and surface leaving the viewport.

**Publishing as a fork**

- Scoped package name, public access (scoped packages default to restricted), repository/homepage/bugs pointed at the fork, and `cordis.patch.yml` exported.
- The client bundle's registration id is injected from `package.json` at build time; client-modules keys its module table by the full package name, so a hardcoded short name would fail with `loaded without registering`.
- The loader entry uses the full package name and keeps a short local row id. Both READMEs document origin, the upstream difference table, the correct install command, the warning against installing both packages, and MIT attribution.
- Two maintenance helpers ship with this release: merge-style repo topics and the upstream catalog PR helper (plugins-viewers entry plus zh/en/ja locales).
